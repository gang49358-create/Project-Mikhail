01 / Основные сведения

Что такое этанол?

Этанол (этиловый спирт) — органическое соединение из группы одноатомных спиртов. Молекула содержит два атома углерода и одну гидроксильную группу –OH, которая во многом определяет свойства вещества.

01 — ФОРМУЛА

Молекулярная формула

C₂H₆O. Структурная формула CH₃–CH₂–OH показывает последовательность атомов и положение гидроксильной группы.

02 — КЛАСС

Органическое соединение

Этанол относится к предельным одноатомным спиртам. Его функциональная группа — гидроксильная группа –OH.

03 — СТРОЕНИЕ

Полярная связь O–H

Кислород сильнее притягивает общую электронную пару. Между молекулами этанола возникают водородные связи.

03 / Химические свойства

Основные реакции

Химические свойства этанола связаны с наличием гидроксильной группы и особенностями углеродной цепи.

Взаимодействие с натрием

2C₂H₅OH + 2Na → 2C₂H₅ONa + H₂↑

Образуется этилат натрия и выделяется водород.

Полное окисление (горение)

C₂H₅OH + 3O₂ → 2CO₂ + 3H₂O

Продукты полного окисления — углекислый газ и вода.

Окисление до альдегида

C₂H₅OH + [O] → CH₃CHO + H₂O

Может образоваться этаналь (уксусный альдегид).

Дальнейшее окисление

CH₃CHO + [O] → CH₃COOH

Этаналь окисляется до уксусной кислоты.

Этерификация

C₂H₅OH + CH₃COOH ⇌ CH₃COOC₂H₅ + H₂O

Образуется сложный эфир — этилацетат.

Дегидратация

C₂H₅OH → C₂H₄ + H₂O

В результате отщепления воды может образоваться этилен.

04 / О проекте

Как создавалась работа

Мы создали этот сайт как наглядное дополнение к изучению темы «Спирты. Этанол». Нам хотелось представить химическую информацию не только в виде текста, но и через современный интерактивный интерфейс.

Для разработки использовались HTML для структуры страницы, CSS для оформления и адаптивного дизайна, а JavaScript — для интерактивной трёхмерной модели молекулы. Визуализация работает на Canvas и не требует сторонних 3D-библиотек.

В результате получилась небольшая цифровая лаборатория, в которой можно изучить состав молекулы, рассмотреть её пространственную модель и повторить основные свойства этанола.
